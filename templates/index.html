Herramienta Docente

Optimiza la preparación de tus clases: genera materiales interactivos y cuestionarios listos para Moodle, y lleva un cuaderno de evaluación a partir de las notas exportadas de Moodle.

{% if not ai_configurado %}
Falta configurar la IA. Copia .env.example a .env y añade tu clave gratuita de la API de Gemini (GEMINI_API_KEY, se crea en aistudio.google.com/apikey) para poder generar materiales y cuestionarios. El cuaderno de evaluación funciona sin esta clave.
{% endif %}

📘 Materiales interactivos

A partir de un texto, PDF, Word o una URL, genera una lección interactiva (con términos clave y autoevaluaciones) y descárgala como paquete SCORM para importar en Moodle.

📝 Cuestionarios autoevaluables

Genera baterías de preguntas (opción múltiple, verdadero/falso, respuesta corta, completar huecos, emparejamiento), revísalas y expórtalas como Moodle XML.

📊 Cuaderno de evaluación

Importa las hojas de calificaciones exportadas de Moodle por evaluación y obtén informes individualizados y la nota final de cada alumno.
